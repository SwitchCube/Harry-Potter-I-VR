# Testing and limitations / Tests und Grenzen

## English

Version 0.1.0 publishes the current HP1 implementation as a preview. The native gameplay implementation comes from the locally selected HP1 build, with a portable packaging and setup layer added for publication.

Previous private checks in the original engine covered stereo rendering and controller actions, the original menu and save flow, spell tracing, flight control logic, chess moves, levitation, troll controls, flute behavior, letters, HUD, mirrors, cinema, remapped actions and DE/EN tutorial lookup. Settings and launcher language were checked again in November 2026. These focused checks do not establish a complete playthrough or compatibility with every headset.

The publication workflow checks the native build, Python session tests, native regression programs, package contents, original-file fingerprints and portable setup. See the release notes for the checks completed on the published package. Test profiles are separate from real game progress.

Still pending: a complete story playthrough, all save checkpoints and long-session recovery, physical controller feel across encounters, flight comfort, hand/head collision protection, final voice quality and broad headset compatibility. Carried objects and less-tested lesson progress may need further work. Only the fingerprinted German engine-433 game inputs are accepted; other editions are not verified. The mod does not replace the original game.

## Deutsch

Version 0.1.0 ist eine Testveröffentlichung des aktuellen HP1-Entwicklungsstands. Die Spielmechanik stammt aus dem lokal ausgewählten Build; für die Veröffentlichung wurden Einrichtung und portables Paket ergänzt.

Frühere private Tests im Originalspiel umfassten Stereoansicht und Controller, Menüs und Spielstände, Zauberzeichnen, Besensteuerung, Schachzüge, Levitation, Troll-Flucht, Flöte, Briefe, Anzeigen, Spiegel, Kino, umbelegte Aktionen und deutsche/englische Lernhinweise. Einstellungen und Launcher-Sprache wurden im November 2026 erneut geprüft. Diese gezielten Tests ersetzen keinen kompletten Spieldurchgang und keine Abnahme mit jeder VR-Brille.

Für das veröffentlichte Paket werden Build, Python- und native Tests, Paketinhalt, Original-Prüfsummen und portable Einrichtung geprüft. Die tatsächlich durchgeführten Prüfungen stehen in den Release-Notizen. Testprofile sind von echten Spielständen getrennt.

Offen bleiben insbesondere der vollständige Storydurchlauf, alle Speicherpunkte, lange Sitzungen, Bediengefühl und Flugkomfort mit echter Brille, Hand-/Kopfkollisionen, abschließende Sprachqualität und weitere Headsets. Getragene Gegenstände und weniger geprüfte Lernaufgaben können weitere Anpassungen benötigen. Unterstützt werden nur die geprüften deutschen Spieldateien mit Engine 433.
