Harry Potter I VR 0.1.0 - First public preview

AI was used during development, including synthetic tutorial speech.

Requirements: your own supported German PC copy of Harry Potter and the
Philosopher's Stone (2001), engine 433 compiled 19 October 2001, Windows 10/11
x64. VR needs SteamVR and a compatible headset with two controllers.
Python is bundled; no development tools are needed to play.

Extract the ZIP into your game folder. Start-HP1VR.cmd and HP1VR must be next
to System. Start SteamVR, open Start-HP1VR.cmd and select Flat or VR.
Use a free original game-menu slot to begin, or the same occupied slot to
continue. English mod text does not imply support for other game editions.

First launch prepares a private copy of verified game files under
%LOCALAPPDATA%\HP1VR. Allow at least 1 GB of additional space, plus growing
saves and backups. The original installation is unchanged. Mod save slots
start empty and are shared by Flat and VR. Original saves are not imported.
Keep the launcher open; closing it during a session only minimizes it.
Exit through the game menu, the launcher or Stop-HP1VR.cmd.
Check-HP1VR.cmd verifies the package and game files without starting a game.

Default controls: left stick moves, right stick snap-turns, A jumps, right
trigger aims/casts, B opens the menu and X advances/fast-forwards scenes.
Hold the lower left grip for inventory and contextual instructions.
B / Escape -> VR Settings: bindings, cinema/3D, language and render size.
Render-size changes apply on the next launch.

Still in development: full story progression, several encounters, physical
headset comfort and broader hardware compatibility need further testing.
Not every scene is confirmed playable without issues.

Close the game before updating. Back up %LOCALAPPDATA%\HP1VR, containing mod
saves and settings, first. The ZIP contains no original game, personal saves,
logs or original voice recordings. Synthetic tutorial packages are included.
